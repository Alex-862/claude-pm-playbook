# Discovery Project Template

This template is for early-stage product discovery where the problem or opportunity is not yet fully defined.

Use this when you want Claude to help synthesise signals, explore opportunity spaces, compare market patterns, and shape hypotheses before moving into PRD or delivery definition.

## Structure

- `business-context/` — company, strategy, customer and constraint context
- `discovery/` — starter brief, internal signals, customer signals and market inputs
- `opportunities/` — selected opportunity areas
- `outputs/` — Claude-generated synthesis and opportunity outputs

## Suggested workflow

1. Complete the starter context files
2. Run `discovery-synthesis`
3. Run `opportunity-mapping`
4. Select a direction manually
5. Use Claude to create a rough concept prototype if useful

Do not jump straight to PRD generation unless the opportunity has been selected and bounded.
